## 1. 화이트박스 테스트

기존 테스트는 "보통 값"으로 규칙을 확인합니다. `WhiteBoxBoundaryTest`는 **기준값 바로 아래 / 정확히 / 바로 위**를 넣어서, 누군가 `>=`를 `>`로 바꾸거나 숫자를 하나 바꿔도 잡히게 합니다.

| 묶음 | 확인하는 경계 |
|---|---|
| 회전 시작 | 44.9°는 아니고 정확히 45°부터 회전. 이미 넘은 상태에서 더 돌려도 한 번만 셈 |
| 깜빡이 인정 | 끈 지 1.5초 이내는 인정, 1.501초는 아님. 켜져 있으면 얼마나 오래됐든 인정 |
| 회전 쿨다운 | 정확히 4초 뒤는 무시, 4.001초 뒤부터 계산 |
| 급한 핸들 | 초당 360°·60°에서 급함, 350°/초나 59°는 아님. 샘플 간격 1초까지만 비교, 1.001초부터는 비교 안 함 |
| 덜컹 브레이크 | 10초에 3번은 덜컹, 10.001초에 걸치면 아님. 두 번이나 꾹 누르고 있기는 아님 |
| 거리·점수 | 0.099km는 주행이 아님, 0.1km는 주행. km당 2점, 상한 40점, 깨끗한 보너스 10점. 주차 중·음수 거리는 무시 |
| 레벨업 | 경험치 100마다, 보너스 포인트 +20은 경험치에 안 들어감 |
| 펫 상태 | 기분 30 / 29, 60 / 59 경계, 배고픔은 기분 60 이상일 때만, 에너지 15% / 16% |
| 성장 단계 | 999.9 / 1000 / 2999.9 / 3000 / 4999.9 / 5000km |
| 미션 | 처음엔 미완료·미수령, 깜빡이 3번째에 완료, 보상은 한 번만 |
| 내비 정보 | 회전 종류별 문구, 알 수 없는 종류의 기본 문구, 음수 거리, 거리 표시 반올림 |
| 위치 | 지구 끝 좌표 허용, 0,0·NaN·무한대 거부, 한국 밖은 "어디도 아님", 에뮬레이터 기본 위치는 경기 |
| 펫의 말 | 모든 성장 단계·반응·이벤트에서 빈 문장을 말하지 않음 |
| 저장 | 스냅샷으로 되살려도 카운터 동일 |

### 변이 검사 (테스트가 정말 잡아내는지)
일부러 코드를 망가뜨려 보고 테스트가 실패하는지 확인했습니다(확인 후 원래대로 복구).

| 망가뜨린 곳 | 실패한 테스트 수 | 새 테스트만 잡았나 |
|---|:-:|:-:|
| 깜빡이 1.5초 비교 `<=` → `<` | 1 | 예 |
| 회전 시작 각도 45 → 46 | 8 | |
| 급한 핸들 속도 360 → 400 | 1 | 예 |
| 덜컹 브레이크 횟수 3 → 4 | 3 | |
| 거리 점수 상한 40 → 50 | 1 | 예 |
| 배고픔 기준 15 → 20 | 2 | |

6개를 모두 잡았고, 그중 3개는 기존 테스트로는 놓치던 것이었습니다.

## 2. 블랙박스 테스트 (에뮬레이터)

입력은 에뮬레이터의 **가상 콘솔**(기어·핸들·브레이크·깜빡이·주행거리·배터리)이고, 확인은 **화면 글자(uiautomator)·앞에 있는 화면·앱 로그·앱이 저장한 값**으로만 합니다.
가상 콘솔 웹 페이지(`http://127.0.0.1:8088/`)를 **브라우저에 열어 둔 채로** 돌려야 합니다(닫혀 있으면 콘솔이 입력을 받지 않음).

| ID | 확인 내용 |
|---|---|
| BB-01 | 앱을 켜면 Vehicle SDK가 시작된다 |
| BB-02 | NaviHelper가 연결된다 |
| BB-03 | NaviHelper 현재 위치로 지역(경기)이 정해진다 |
| BB-04 | 차량·내비 권한 6개가 모두 허용되어 있다 |
| BB-05 | 주차(P)일 때 펫 화면이 맨 앞에 있다 |
| BB-06 | 주행(D)으로 바꾸면 펫 화면이 닫히고 서비스는 계속 산다 |
| BB-07 | 주행거리 +1km는 반영, 큰 점프(+8km)는 무시 |
| BB-08 | 깜빡이 켠 회전이 늘어난다 |
| BB-09 | 깜빡이 없는 회전이 늘고 기분이 내려간다 |
| BB-10 | 핸들을 빠르게 돌리면 급한 핸들이 늘어난다 |
| BB-11 | 브레이크 10초 3번이면 덜컹 브레이크가 늘어난다 |
| BB-12 | 브레이크 한 번 길게 밟는 것은 덜컹이 아니다 |
| BB-13 | P로 돌아오면 화면이 저절로 열리고, 결과 카드와 운전 기록 한 줄이 생긴다 |
| BB-14 | EV 배터리 10%면 캐릭터 정보에 "배고픈", 80%면 "평상시" |
| BB-15 | 연료 % (이 에뮬레이터는 전기차라 시험 불가: 건너뜀) |
| BB-16 | 길 안내를 시작하면 NaviHelper가 경로(대구)를 알려 준다 |
| BB-17 | 앱을 껐다 켜도 저장된 값과 이름이 그대로다 |
| BB-18 | 시험하는 동안 앱이 죽지 않았다 |

### 2-2. 앱 안 조작 시험 (`run_ui_features.py`, 14개)

차를 세워 둔(P) 상태에서 운전자가 앱 안에서 누르는 것들을 실제로 눌러서 확인합니다. 버튼은 화면 글자로 찾고(글자가 접근성 트리에 없는 설정 화면은 위치로), 결과는 화면 글자와 앱이 저장한 값으로 판정합니다. 가상 콘솔은 필요 없습니다.

| ID | 확인 내용 |
|---|---|
| UI-01 | 상점에서 구매하면 포인트가 가격만큼 줄고 버튼이 "보유 중"이 된다 |
| UI-02 | 레벨이 모자란 소품(🔒)은 눌러도 살 수 없다 |
| UI-03 | 인벤토리에서 산 모자를 입고 벗을 수 있고, 저장된다 |
| UI-04 | 산 가구(화분)를 방에 놓고 치울 수 있다 (상점 목록을 스크롤해서 구매) |
| UI-05 | 끝낸 미션의 보상을 받으면 포인트가 늘고 "받음"이 되며, 다시 눌러도 또 주지 않는다 |
| UI-06 | 설정에서 다크/라이트를 바꾸면 저장되고 화면이 다시 만들어진다 (라이트=1, 다크=2) |
| UI-07 | 설정에서 "차 옆에서 따라가기"를 켜고 끄면 저장된다 |
| UI-08 | 운전 기록 삭제: 취소하면 그대로, 지우면 기록 0줄, 배지는 남는다 |
| UI-09 | 미니게임을 시작해서 플레이하면 결과 화면(다시/나가기)이 나온다 |
| UI-10 | 지도 도감을 열고 컬렉션을 열고 닫을 수 있다 |
| UI-11 | 줍기가 일어나면 지도 도감의 "전체 N/85"가 늘어난다 |
| UI-12 | 운전 기록에서 달력, 점수 기준 설명 창을 열 수 있다 |
| UI-13 | 배지를 눌러 조건과 진행 상황을 볼 수 있다 |
| UI-14 | 거리를 올리면 성장 단계(유아기 → 반항기 → 성인기)가 바뀐다 |

### 알아 둘 것 (고치지 않았음)
- **설정 화면의 글자(라이트/다크, 따라가기, 삭제 확인)는 접근성 트리에 안 잡힙니다.** 화면 읽기 도구를 쓰는 사용자에게는 이 옵션이 안 읽힙니다(차량용으로는 우선순위가 낮음). 시험은 위치로 눌러서 확인했습니다.
- **미니게임에서 코인을 모아 포인트를 받는 경로**는 사람이 직접 하는 플레이가 필요해서 자동 시험으로는 시작·충돌·결과 화면까지만 확인했습니다(코인 규칙은 단위 테스트가 확인).
- **작은 글자**: 홈의 "눌러서 모든 배지 보기", 지도 도감 안내, 운전 기록의 보조 설명 등 약 16~19px(2560×1440 화면 기준)인 글자가 많습니다. 차 자체의 작은 글씨(17px 안팎)와 비슷한 수준이라 오류로 보지 않았지만, 디자인에서 최소 크기를 정하면 좋습니다.
