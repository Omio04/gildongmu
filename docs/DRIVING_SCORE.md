# 운전펫 추정 점수 v1 · 블루링크 연계 방향

확인일: 2026-11-13. 블루링크의 공개 평가 항목을 참고한 자체 실험 점수입니다. 현대차 공식 계산식의 재현이나 공식 연계를 완료한 것은 아닙니다.

## 공식 근거
- [현대차 데이터 API](https://developers.hyundai.com/web/v1/hyundai/data_api): 운전습관 API에서 최근 90일 운행을 분석한 점수를 제공한다고 안내합니다.
- [현대차 공식 발표](https://www.hyundaimotorgroup.com/ko/news/hyundai-motor-company-manufacturer-data-certified-used-car-trust): 급가속·급감속·급출발·심야주행 등으로 점수를 산정한다고 설명합니다. 해당 발표의 1,000km 기준을 이 자체 모델이 동일하게 재현하지는 않습니다.
- [이용 절차](https://developers.hyundai.com/web/v1/hyundai/faqs): 개발 프로젝트 생성, 연동 테스트, 상용화 심사를 거칩니다. 이번 앱의 운전점수 조회 권한·실제 규격·승인은 미확보입니다.

## 실제 구현
1. 기존 위치 권한을 이용한 GPS 속도 수신(약 1초 간격 요청).
2. D단의 실제 주행만 집계. P단에서 종료하며 N/R 동안 새 속도 판정은 하지 않습니다.
3. 속도 정확도 0.5m/s 이하, 2초 이내 최신 값, 간격 0.5~2초, 정상 시계 간격만 사용합니다. 가상 위치·잘못된 수치·12m/s² 초과 점프는 거릅니다.
4. 두 속도의 오차 합을 시간으로 나눈 값을 가속도에서 빼고 판정합니다. 누락 구간을 부드러운 주행으로 간주하지 않습니다.
5. 90일 내 종료한 주행 요약을 합산합니다. GPS 측정 거리 10km·유효 측정 600초·전체 주행 시간 대비 수신율 80%를 모두 만족할 때만 점수가 생깁니다.

## 자체 기준 (현대차 기준값 아님)
| 항목 | 판정 | 차감 |
|---|---|---|
| 급가속 추정 | 오차 제외 가속도 3.0m/s² 이상 | 100km당 횟수 × 2, 최대 35점 |
| 급감속 추정 | 오차 제외 감속도 3.5m/s² 이상 | 100km당 횟수 × 2, 최대 35점 |
| 급출발 추정 | 직전 10km/h 이하에서 급가속 | 100km당 횟수 × 2, 최대 20점 |
| 심야주행 | 한국 시간 23~05시 이동 | 유효 측정 시간 중 비율 × 10, 최대 10점 |

100에서 차감을 빼고 반올림합니다. 급출발은 급가속과 중복 집계하지 않으며 이어지는 동일 이벤트는 한 번 셉니다. 이벤트 간 최소 간격은 3초입니다. 데이터가 부족하면 0점·100점 대신 미측정으로 표시합니다. 합산된 거리와 횟수로 계산하며 개별 주행 점수를 단순 평균하지 않습니다.

급가속·급감속은 운전 상황을 판단하지 못하는 추정치입니다. 긴급 회피나 심야 근무를 위험한 운전으로 단정할 수 없고 실차 검증·가중치 보정이 필요합니다. GPS 1Hz의 한계로 짧은 이벤트가 누락될 수 있습니다. 전체 안전도를 보장하는 점수가 아닙니다.

## 공식 점수 연결 준비
`OfficialScoreProvider`와 `OfficialDrivingScore`는 앱 내부 연결 경계입니다. 현대차 API 응답 형식을 추측해 만든 것이 아닙니다. 현재 `BluelinkNotConnected`는 값 없음만 반환합니다.

향후: 이용 가능한 공식 API와 권한 확보 → 사용자 동의·차량 선택 → 서버에서 공식 인증/조회 → 기준일과 출처가 포함된 공식 점수 제공 → 실험 점수와 나란히 비교·보정 → 검증된 점수 기반 성장·미션 도입. 공식 점수를 얻지 못했을 때 자체 점수를 공식 점수로 바꿔 표시하지 않습니다. 보험 할인·현대차 제휴는 확정 사실이 아닙니다.

## 보관·시연
- 좌표·개별 속도는 저장하지 않고 종료 시각·측정 거리/시간·이벤트 횟수·심야 시간·산식 버전만 로컬 저장합니다.
- 90일 범위 밖 기록은 새 기록을 추가할 때 정리하며 조회에서도 제외합니다.
- 기존 깜빡이 달력·배지의 의미와 저장 형식을 유지합니다.
- `score_demo`: 메모리상의 87점 예시. 실제 기록과 보상은 변경하지 않습니다. `score_live` 또는 프로세스 재시작으로 종료합니다.
- 새 점수는 실차 검증 전이므로 펫 보상·기분에 자동 반영하지 않습니다. 주차 후 기록 화면에서만 확인합니다.

```powershell
adb shell am broadcast --user 10 -a com.drivepet.DEMO -p com.drivepet.app --es cmd score_demo
adb shell am broadcast --user 10 -a com.drivepet.DEMO -p com.drivepet.app --es cmd score_live
```
