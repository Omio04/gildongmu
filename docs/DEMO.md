# 시연 시나리오 (60초 영상 · PT 시연)

**한 줄:** 막힌 길에서 말로 물어 이웃의 답을 듣고, 도착 시간에 맞춰 가는 길 가게에서 받는다.

## 준비 (촬영 전 5분)
1. 서버: `python server/app_server.py 8080` (방화벽 8080 허용).
2. 에뮬레이터에 `apk/이정준_길동무_release.apk` 설치 후 시작. 첫 실행은 소개 → 동의 → 프로필(건너뛰기 가능).
3. **이웃 한 대:** 폰 브라우저에서 `http://<PC주소>:8080/neighbor` → 프로필을 고르고 "이웃으로 참여". (폰이 없으면 `python tools/neighbor_demo.py --north-m 80 --answer`가 두 번째 차 역할을 합니다. 시험용 도구라고 영상에 밝히세요.)
4. 가게 화면: PC 브라우저에서 `http://localhost:8080/shop` (주문이 들어오는 모습을 화면 분할로 보여 줍니다).
5. 주행 상태를 보이려면 가상 콘솔에서 기어 D + 가속, 또는 디버그 빌드에 `--es force_state moving`.

## 장면 (총 60초)
| 초 | 화면 | 말/동작 |
|---|---|---|
| 0–8 | 도로 위 내 차(흰색)와 이웃 차(파랑), 맨 위 내비 안내 줄 | "정체 구간. 앞에 앱을 쓰는 이웃이 보여요." |
| 8–20 | "왜 막혀요?" 한 번 터치(또는 "왜 막혀?"라고 말하기) | 이웃 폰에서 "사고"를 고르면 내 화면에 답이 뜸 |
| 20–28 | 답 옆 "도움이 됐어요" | 이웃 폰에 고맙다는 알림, 이웃 점수 +1 |
| 28–35 | 주행 시작(가속) → 화면이 주행 모드로 바뀜 | "달리면 버튼이 사라지고 말로만 돼요." |
| 35–50 | "커피 마시고 싶어" → 가까운 가게 한 곳 + 메뉴 하나 → "결제" | 오른쪽 가게 화면에 주문이 뜸("3분 뒤 조리 시작") |
| 50–60 | 마무리 자막 | "샘플 가게 · 모의 결제 · 이웃은 실제로 접속한 차만" |

## 영상에 꼭 밝힐 것 (심사에서 물으면 같은 답)
- 가게·결제는 시험용(샘플, 모의)이고 가게에 주문이 실제 전달되지는 않지만, **서비스 안에서는 가게 화면까지 이어집니다.**
- 음성 인식은 안드로이드 기본 인식이고 에뮬레이터에는 마이크 인식이 없어, 영상의 음성 장면은 말한 글자를 넣어 보여 주는 시험 옵션(`--es say "..."`)을 쓴 것이라고 밝히거나 폰 화면에서 찍습니다.
- 이웃은 실제 접속한 차만 도로에 나옵니다(가짜 차 없음).
