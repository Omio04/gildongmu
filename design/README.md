## 앱을 한 문장으로
막힌 길에서 근처 차에게 묻고 알리고 도움받는 차량용 앱. 덤으로 가는 길 가게를 말로 묻고 메뉴·가격을 듣고 결제(모의)까지 합니다. 주행 중에는 터치를 막고 음성으로, 정차·주차 중에는 터치도 됩니다.

## 디자이너가 돌려줄 것
1. 고친 화면 PNG (낮/밤)
2. `전달형식_DESIGN_HANDOFF.md`의 **값 표** (색 hex, 글자 sp, 크기·여백·모서리 dp)
3. 바꾼 이유 한 줄

## 알려진 약한 곳 (디자인 도움이 필요한 곳)
- 홈(06): 한 화면의 핵심이 하나가 아님. 무엇이 먼저 보여야 하는지 정해야 함.
- 02 동의 화면: 글이 많고 버튼이 잘림.
- 15 주행 중: 터치 요소를 숨길지 흐리게 둘지 정해야 함.
- 아이콘: 경고 삼각형이 많음. 일관된 세트가 필요함.

## 확인 못 한 것
- 위 캡처는 에뮬레이터(차량용) 화면이고 실제 차량 화면은 보지 못했습니다.
- 가게·가격·전화번호·결제는 모두 시험용 샘플입니다.
