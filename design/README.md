# 운전펫 디자인

현재 앱의 디자인 소스는 `character/`와 `regions/`입니다. 지역 그림은 낮과 밤 모두 사용합니다. `regions/README.md`에 생성 방법이 있습니다.

`app_icon_1024.png`는 앱 아이콘 원본입니다. 이 폴더의 다른 최상위 PNG는 디자인 참고 시안이며 실행 앱의 최신 화면이 아닙니다. 실행 화면은 `../screenshots/`를 참고하세요.

현재 스타일·캐릭터 구현은 `../app_code/app/src/main/java/com/drivepet/app/Look.kt`, `PetPainter.kt`, `RoomPainter.kt`에 있습니다.
