# 디자인 → 개발 전달 형식

디자인 툴은 아무거나 쓰고, **아래 4가지만 같은 모양으로 넘깁니다.** 개발자는 이 값을 보고 `Theme.kt`와 화면 코드에 옮깁니다. 디자이너가 코드를 만지지 않아도 됩니다.

## 1. 폴더와 이름
```
design/
  01_홈/
    01_홈_낮.png          ← 1408×792 가로, 낮 테마
    01_홈_밤.png          ← 밤 테마
    01_홈_값표.md          ← 아래 3번 표
  02_주문카드/ ...
  assets/
    ic_pin.svg  ic_cafe.svg ...   ← 아이콘 (SVG, 이름은 ic_영문소문자)
  colors.md                ← 모든 색 (낮/밤)
```
- 화면 번호는 `docs/ONBOARDING.md` 5번 화면 목록과 같게 씁니다.
- 파일은 **GitHub `design/` 폴더에 올리거나**, 공유 드라이브 링크를 `design/README.md`에 적습니다. (용량이 큰 원본은 링크만)

## 2. 화면 PNG
- **크기 1408×792**(1px = 1dp). 오른쪽 패널은 약 489 폭.
- **낮/밤 두 장**. 상태가 여러 개면 따로: 기본 / 눌렀을 때 / 비활성 / **주행 중(터치 잠금)** / 비어 있음 / 오류.
- 화면 안의 글은 **실제 문구**로 씁니다(자리 채우기 글 금지). 문구는 해요체, "닫기" (취소 대신).

## 3. 값 표 (화면마다 한 장)
| 요소 | 색 (낮/밤) | 글자 (크기sp·굵기) | 크기 (가로×세로dp) | 여백 (안/바깥 dp) | 모서리 dp | 비고 |
|---|---|---|---|---|---|---|
| 가게 이름 | #0F172A / #E6ECF5 | 20 · 굵게 | - | 아래 8 | - | 한 줄, 넘치면 … |
| 결제하기 버튼 | #007DA6 글자 #FFFFFF | 18 · 굵게 | 가로 채움×56 | 안 14 | 16 | 터치 44 이상 |
- **8의 배수** 간격을 씁니다(4, 8, 16, 24).
- 글자는 **sp**, 크기·간격은 **dp**로 적습니다. 본문은 14sp 이상.
- 색은 hex 6자리. 투명도는 따로 적습니다(예: 흰색 80%).

## 4. 아이콘·그래픽
- **SVG**로 내보냅니다(선 두께 통일, 한 화면에 아이콘 한 종류). 개발자는 Android Studio의 Vector Asset으로 앱에 넣습니다.
- 그라데이션과 장식 효과는 쓰지 않습니다.

## 차량 화면 규칙 (시안이 이걸 어기면 돌려보냅니다)
- 주행 중 화면에는 **터치 요소를 두지 않고**, 읽을 것과 말로 할 것만 둡니다.
- 터치 영역 **44dp 이상**, 글자 대비 **4.5:1 이상**.
- **한 화면의 핵심은 하나**. 나머지는 작게.
- 동영상, 글자 입력창은 쓰지 않습니다.

## 주고받는 순서
1. 디자이너: 화면 한 개를 폴더 규칙대로 올립니다.
2. 개발자: 반영해서 에뮬레이터 캡처를 같은 폴더 `반영_화면.png`로 올립니다.
3. 디자이너: 캡처를 보고 코멘트(어긋난 곳은 값 표의 행으로 지목).
4. 위를 한 화면씩 반복합니다(전부 모아서 한 번에 넘기지 않습니다).
- 우선순위 화면 먼저: **홈, 주문 카드, 결제·주문 내역, 주행 중 화면**.
